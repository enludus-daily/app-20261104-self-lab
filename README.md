# じぶん実験室

「朝スマホを見ないと調子がいい気がする」——その「気がする」を、くじで確かめる iOS アプリ（SwiftUI、iOS 26 以降）。

## 世界観

**このアプリでは、理科の実験ノートの方眼の記録用紙が「実験ごとのページ」になり、おみくじの筒が「今日のやる日・やすむ日の割り付け」に、ハンコが「結果」になる。**

| 題材の現物 | 部品（自作の Shape / Canvas） | ファイル |
|---|---|---|
| 方眼の記録用紙 | `GridPaper`（方眼 16pt・線 0.5・余白の赤線）、`NotebookPage`（紙・角丸 18・少し傾ける） | `Paper.swift` |
| クリップ・ラベルシール | `PaperClip`（針金の曲線）、`LabelSticker`（色の帯・-2° 傾け・線の影） | `Paper.swift` |
| おみくじの筒とくじの棒 | `OmikujiTube`（六角の筒・木目・「みくじ」の札）、`KujiStick`、振る動き | `Omikuji.swift` |
| ハンコ | `Hanko`（二重丸・朱肉のかすれを固定の乱数で）、途中は鉛筆の点線 | `Paper.swift` |
| 記録表 | `RecordTable`（やる日＝朱・やすむ日＝藍、点数で濃さ 5 段階、できなかった日は斜線、今日は蛍光ペン） | `Paper.swift` |
| ノートの背表紙と棚 | `NotebookSpine`（縦書きのラベル・小さなハンコ）、木の棚板 | `Paper.swift`・`ContentView.swift` |
| 日付スタンプ | `DateStamp` | `ContentView.swift` |

## トークン（`Theme.swift`）

- 色：1 色ごとに accent / soft / deep / paper / decor の 5 段階。朱（やる日・効果あり）、藍（やすむ日・逆効果）、蛍光ペン（今日・抜けの知らせ）、木（筒・棚）。紙・方眼・インク・線はライトとダークの両方を持つ
- 意味のある段階：記録の点数 1〜5 でマスの濃さ（0.28 / 0.45 / 0.62 / 0.8 / 1.0）、結果で色（朱・藍・墨・鉛筆）
- 書体：見出しと数字はセリフ（明朝調）、本文はゴシック。大きな数字は字間を詰め（-1.5〜-2）、小さなラベルは開ける（0.6）
- 角丸：4（ラベル）・8（マス・紙片）・12（ボタン）・18（ページ）。余白：4 / 8 / 12 / 16 / 24 / 32
- 影：紙（0.08・r10・y4）、浮いた物（0.18・r8・y6）、線の影（r0・y1）の 3 種類だけ
- グラデーションは使わない

## 手応えの表

| できごと | 動き | 振動 | 音 |
|---|---|---|---|
| 押す | 判子調のボタンが下辺の影ごと 3pt 沈む（spring 0.18） | — | なし（※） |
| 1 つ成功（点数を選ぶ） | 数字に鉛筆の丸が trim 0→1 で 0.35 秒で描かれ、数字が 1.15 倍 | `.selection` | なし |
| 連続・まとめて成功（記録表が埋まる・続けた日数） | マスが 0.4→1 のバネで塗られる、日数は numericText | `.success`（記録したとき） | なし |
| 失敗・間違い（点数を選ばずに記録／題が空・医療の語で始められない） | 横揺れ 0.42 秒（減衰）＋次の一歩の一文 | `.error` | なし |
| 完了（記録した／実験が終わって結果が出る） | 記録：紙片が固定の乱数で散る（24 片）。結果：ハンコが 0.6→1 のバネで押される | `.success` | なし |
| 場面の切れ目（今日のくじを引く） | 筒が左右に 16°→-14°→11°→-8°→5°→-2°→0° と揺れ（0.65 秒）、くじの棒がせり上がり、結果の紙片が 0.6→1 で出る | 揺れで `.impact(.medium)`、札が出て `.impact(.heavy)` | なし |

※ 音は鳴らさない：静かな記録の道具で、消音のままでも同じ価値になるように（設定にも明記）。
動きを減らす設定（`accessibilityReduceMotion`）では、揺れ・紙片・ハンコの弾み・オンボーディングの動く見本を止め、値を直接変える。振動は設定で切れる。

## 中身

- 実験の型 42（睡眠・朝の過ごし方・集中・気分・体を動かす・デジタル習慣・暮らし の 7 分類 × 6）。それぞれ、質問・おすすめの日数・翌朝に記録するか・なぜ・続けるコツ・よくある落とし穴（`App/Resources/templates.json`）。医療・服薬・食事制限は入れない（テストで確かめる）
- 気になることを書くと Apple Intelligence（端末の中のモデル）が案を 3 つ。使えない端末では理由と、型からの案
- 毎日開く理由：今日のくじ、記録表、続けた日数（途切れても「おかえりなさい」）、実験ノートの棚、結果カード（1080×1920 の画像。数字と言葉だけ）
- 結果：平均の差（言葉・Swift Charts・ハンコ）と、くじを全通り入れ替えた差の分布の図・コインやサイコロのたとえ
- 状態：実験なし・記録の抜け・途中でやめた・結果待ち（あと何日）・Apple Intelligence が使えない・始められない下書き、それぞれに次の一歩の一文
- 最初の 10 秒：3 ページのオンボーディング（くじを振る動く見本）＋見本の実験 3 つ（結果あり・途中でやめた・進行中）

## iPhone Duo

内側の大きな画面では、左に今日のくじと棚、右に実験ノート（記録表と結果を横に並べる）。`NavigationSplitView` と size class で切り替え。閉じた外側の画面やほかの iPhone では 1 列に重なる。

## 作らなかったもの

通知、ウィジェット（App Group の署名の設定が要り、毎日の自動の流れで署名のエラーを避けるため）、ヘルスケアとの連携、英語（日本語だけ）、医療・服薬・食事制限に関わる実験。

## データ

すべて端末の中（UserDefaults）。通信・ログイン・解析・広告はない。

## 開発

- ビルドとテストは GitHub Actions（`.github/workflows/ci.yml`、iPhone Duo のシミュレータ）。手順は `docs/daily-runbook.md`、品質の基準は `.claude/skills/app-quality-bar`
- 処理は画面から切り離してある：くじ `Scheduler`、結果 `Analyzer`（並べ替え検定・差の分布）、保存 `ExperimentStore`、型 `TemplateLibrary`、案 `ExperimentDesigner`（テストでは偽物）、画面の文 `Greeting`・`DetailText`・`DraftProblem`

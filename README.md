# じぶん実験室

「朝スマホを見ないと調子がいい気がする」——その「気がする」を、くじで確かめて**カードにする** iOS アプリ（SwiftUI、iOS 26 以降）。

毎朝、伏せたカードを 1 枚ずつめくると、きのうの記録・集まった証拠・きょうのくじ（やる日／やすむ日）が出る。8〜14 日たつと結果発表。並べ替え検定の結果が「効いた」「思い込みだった」「逆効果」のカードになって図鑑に入る。★は偶然の確率で決まる。

## 組み合わせ（悩み × エンタメ）

**〈習慣を試して毎日記録する〉なのに〈トレーディングカードを開封して集める〉みたい。**

- しんどい行動（毎日の記録）がそのまま遊びの入力：記録した点数がカードの種類と★を決める。記録が抜けていると、けさの開封は「その場で記録」のカードで止まり、記録すると先へめくれる
- 「思い込みだった」も 1 枚のカード。始める前の予想（きっと効く／半信半疑／効かないと思う）と逆なら「思い込みを破った」の印
- 統計の正しさが強み：くじは半分ずつ・同じ側は 3 日まで。結果は並べ替え検定（全部の組み合わせ）。**結果は最後の日まで伏せる**（途中で何度も見ると、偶然の波を効果と見まちがえやすい）。これが結果発表の演出にもなる
- 比べた 3 案と点数は daily-ideas#4

## 画面（iOS 26 の標準の TabView・Liquid Glass）

| タブ | 中身 |
|---|---|
| きょう | 重ねた伏せカード「けさの開封」と「めくる」（画面の上半分。Duo の外側の画面でもスクロールなし）→ きょうのくじと今夜の記録 → 抜けている日 → 進行中 → 図鑑の新着 |
| 図鑑 | 型ごとの枠（無料 42・Pro 24）。まだの枠は点線、押すと中身と「始める」。種類で絞り込み、集めた枠・効いた・思い込み・破ったの数 |
| 実験 | 進行中と終わった実験の一覧。進行中は集まった証拠（点）と次の一歩。終わったものはカードの中身 |
| 設定 | Pro・書き出し・振動・見た目・しくみ・プライバシー |

カードの中身：大きなカード、ことば、予想の答え合わせ、やる日とやすむ日の平均（数字は図の上に置き、棒に重ねない）、くじを全部入れ替えた差の分布とたとえ、追試（Pro）、共有画像（名前・日付なし）。

### 参考にしたアプリと借りたもの（ui-reference）
参考：StudyReel（トーン）＋ Pokémon Sleep
1. Pokémon Sleep の朝の結果発表（たまったものを 1 枚ずつめくる）→ けさの開封
2. Pokémon Sleep の図鑑（まだの枠は影、集めた数 / 全体）→ 図鑑タブの点線の枠と「集めた枠 n / 66」

### iPhone Duo
size class で切り替える（機種では決めない）。内側の大きな画面（横が regular）では、きょうは 2 列（左に開封とくじ、右に進行中と図鑑）、図鑑は左に一覧・右に選んだカードを大きく、実験は NavigationSplitView。閉じた外側の画面とほかの iPhone では 1 列。CI は `screenshot-posture: open` で開いた姿勢も撮る。

## トーン（StudyReel。`look.md` §0）
- 主色は sky 1 系統（accent `#9EC3E2` L0.75）、差し色は peach（`#F4BBA4` L0.80）。やる日・効いた＝peach、やすむ日・思い込み＝sky、逆効果＝mist。分類ごとの虹色にしない
- deep（`#5E8DB8`・`#C0785E`）は白文字のボタンと小さな文字だけ
- 地 `#F3F6F9`、カード `#FCFDFE`、文字 `#2E3A46`、補助 `#8E9AA6`、線 `#E3E9EF`。ダーク用も同じ段階
- 見出しと数字はセリフ（大きな数字は字間 -3）、小さなラベルは字間 0.6。太字はほぼ使わない
- 影は 3 種類（0.06・0.08・浮いたカード 0.18）。グラデーションは箔のきらめきだけ（光の表現という理由がある所）
- `python3 scripts/tone-check.py` → exit 0（強い色 0 件）

## 手応えの表（`feel.md`）

| できごと | 動き | 振動 | 音 |
|---|---|---|---|
| 押す | ボタンが 0.98 倍・少し薄く（easeOut 0.2） | — | なし |
| 1 つ成功（点数を選ぶ） | 数字を細い輪が trim でなぞる（0.35 秒） | `.selection` | なし |
| 場面の切れ目（カードをめくる） | 縦の軸で 180° 回る（spring 0.6 / 0.82）、次のカードは右から入る | `.selection` | なし |
| 連続（けさの開封を進む） | 上の進み具合の点が伸びる、束がゆっくり呼吸 | — | なし |
| 失敗・間違い（題が空・医療の語・上限） | 次の一歩の一文がフェードで出る | — | なし |
| 完了（記録した／結果発表でカードを手に入れた） | カードが表になり、★2 以上は箔が光る。数字は numericText | `.success` | なし |

音は鳴らさない（消音でも同じ価値）。動きを減らす設定では、めくり・呼吸・箔・オンボーディングの動く見本を止め、値を直接変える。振動は設定で切れる。

## 中身
- 実験の型 66：無料 42（睡眠・朝・集中・気分・体を動かす・デジタル・暮らし × 6）＋ Pro 24（勉強・仕事 12、人と休日 12）。それぞれ質問・日数・翌朝に記録するか・なぜ・コツ・落とし穴（`App/Resources/templates.json`）。医療・服薬・食事制限は入れない（テストで確かめる）
- 証拠のカードのひとこと 30（種と日で決まる）
- 毎日開く理由：けさの開封（きのう・証拠・くじ）、結果発表とカード、図鑑の空き枠、予想の答え合わせ、続けた日数（途切れても責めない）、共有画像
- 状態：実験なし・記録の抜け・結果待ち（あと何日）・結果が出なかった・途中で終えた・無料の上限・価格を読み込めない、それぞれ次の一歩の一文
- 最初の 10 秒：3 ページのオンボーディング（カードがめくれる動く見本）＋見本の実験 4 つ（効いた・思い込みだった・途中でやめた・進行中で今朝のカードあり）

## 課金

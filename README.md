# じぶん実験室

「朝スマホを見ないと調子がいい気がする」——その「気がする」を、くじで確かめる iOS アプリ（SwiftUI、iOS 26 以降）。

## 世界観

**このアプリでは、理科の実験ノートの方眼の記録用紙が「実験ごとのページ」になり、おみくじの筒が「今日のやる日・やすむ日の割り付け」に、ハンコが「結果」になる。**

| 題材の現物 | 部品（自作の Shape / Canvas） | ファイル |
|---|---|---|
| 方眼の記録用紙 | `GridPaper`（方眼 16pt・線 0.6・淡い余白線）、`NotebookPage`（紙・角丸 18・線 0.6。方眼と傾けは今日のページだけ） | `Paper.swift` |
| クリップ・ラベルシール | `PaperClip`（針金の曲線）、`LabelSticker`（色の帯・-2° 傾け・線の影） | `Paper.swift` |
| おみくじの筒とくじの棒 | `OmikujiTube`（六角の筒を淡い面と細い線で・「みくじ」の札）、`KujiStick`、小さく振る動き | `Omikuji.swift` |
| ハンコ | `Hanko`（細い線の二重丸・軽く押したかすれと透け、固定の乱数で）、途中は点線 | `Paper.swift` |
| 記録表 | `RecordTable`（やる日＝peach・やすむ日＝sky、点数で濃さ 5 段階、できなかった日は斜線、今日は細い sky の枠） | `Paper.swift` |
| ノートの背表紙と棚 | `NotebookSpine`（縦書きのラベル・小さなハンコ）、細い線の棚 | `Paper.swift`・`ContentView.swift` |
| 日付 | `DateStamp`（セリフ・字間 0.6 の小さな日付） | `ContentView.swift` |

## トーン（StudyReel に寄せる。`.claude/skills/app-quality-bar/references/look.md` §0）

オシャレ・透明感・清潔。ほぼ白の地、淡い色、セリフの見出しと数字、細い線、弱い影、静かな動き。`python3 scripts/tone-check.py` が exit 0（強い色 0 件）。

## トークン（`Theme.swift`）

- 色は 1 系統＋差し色 1 つ：主＝sky（accent `#9EC3E2` L0.75）、差し色＝peach（accent `#F4BBA4` L0.80）。やる日＝peach、やすむ日＝sky を、淡い面とアイコン（☀︎ / ☾）・文字で分ける。今日の印・お知らせは sky に寄せた無彩色（mist）、筒と棚は淡い石（stone）
- deep（`#5E8DB8`・`#C0785E`、彩度 0.5 以下）は白文字のボタンと小さな文字だけ。広い面には塗らない
- 地はほぼ白（`#F3F6F9` L0.96）、紙 `#FCFDFE`、文字 `#2E3A46`、補助 `#8E9AA6`、線 `#E3E9EF`。ダーク用も同じ段階で持つ
- 意味のある段階：記録の点数 1〜5 でマスの濃さ（0.28 / 0.45 / 0.62 / 0.8 / 1.0）、結果で印の色（peach・sky・文字・補助）
- 書体：見出しと大きな数字はセリフ（medium / regular）。大きな数字は字間 -3、小さなラベルは 0.6。太字はほぼ使わない
- 線：方眼 0.6、紙とマスの線 0.6、ハンコの線は細く。影は opacity 0.06（紙）と 0.08（くじの紙片・結果カード）だけ
- 飾り（方眼・クリップ・ラベルシール・傾け）は、ホームの「今日のページ」と結果カードだけ。ほかのページは無地の紙と細い線
- 角丸：4（ラベル）・8（マス・紙片）・12（ボタン・札）・18（ページ）。余白：4 / 8 / 12 / 16 / 24 / 32
- グラデーションは使わない

## 手応えの表（StudyReel の静かな動き。`feel.md` §2）

| できごと | 動き | 振動 | 音 |
|---|---|---|---|
| 押す | ボタンが 0.98 倍・少し薄くなる（easeOut 0.2） | — | なし（※） |
| 1 つ成功（点数を選ぶ） | 数字に細い鉛筆の丸が trim で 0.35 秒で描かれる | `.selection` | なし |
| 連続・まとめて成功（記録表が埋まる・続けた日数） | マスがフェードで色づく（easeOut 0.3）、数字は numericText | — | なし |
| 失敗・間違い（点数を選ばずに記録／題が空・医療の語で始められない） | 次の一歩の一文がフェードで出る（揺れはない） | — | なし |
| 完了（記録した／結果が出た） | ハンコがそっと置かれる（1.04→1・フェード 0.35 秒）、差の数字は numericText | `.success` | なし |
| 場面の切れ目（今日のくじを引く） | 筒が 1.05 倍に浮いて、3°→-3°→2°→0° と小さく揺れ（0.5 秒）、棒と紙片がフェードで出る | `.selection` | なし |

※ 音は鳴らさない：静かな記録の道具で、消音のままでも同じ価値になるように（設定にも明記）。紙吹雪・大きな揺れは使わない。
動きを減らす設定（`accessibilityReduceMotion`）では、揺れ・浮き・ハンコの置く動き・オンボーディングの動く見本を止め、値を直接変える。振動は設定で切れる。

## 中身

- 実験の型 42（睡眠・朝の過ごし方・集中・気分・体を動かす・デジタル習慣・暮らし の 7 分類 × 6）。それぞれ、質問・おすすめの日数・翌朝に記録するか・なぜ・続けるコツ・よくある落とし穴（`App/Resources/templates.json`）。医療・服薬・食事制限は入れない（テストで確かめる）
- 気になることを書くと Apple Intelligence（端末の中のモデル）が案を 3 つ。使えない端末では理由と、型からの案
- 毎日開く理由：今日のくじ、記録表、続けた日数（途切れても「おかえりなさい」）、実験ノートの棚、結果カード（1080×1920 の画像。数字と言葉だけ）
- 結果：平均の差（言葉・Swift Charts・ハンコ）と、くじを全通り入れ替えた差の分布の図・コインやサイコロのたとえ
- 状態：実験なし・記録の抜け・途中でやめた・結果待ち（あと何日）・Apple Intelligence が使えない・始められない下書き、それぞれに次の一歩の一文
- 最初の 10 秒：3 ページのオンボーディング（くじを振る動く見本）＋見本の実験 3 つ（結果あり・途中でやめた・進行中）

## iPhone Duo

内側の大きな画面では、左に今日のくじと棚、右に実験ノート（記録表と結果を横に並べる）。`NavigationSplitView` と size class で切り替え。閉じた外側の画面やほかの iPhone では 1 列に重なる。

## 作らなかったもの

通知、ウィジェット（App Group の署名の設定が要り、毎日の自動の流れで署名のエラーを避けるため）、ヘルスケアとの連携、英語（日本語だけ）、医療・服薬・食事制限に関わる実験。

## データ

すべて端末の中（UserDefaults）。通信・ログイン・解析・広告はない。

## 開発

- ビルドとテストは GitHub Actions（`.github/workflows/ci.yml`、iPhone Duo のシミュレータ）。手順は `docs/daily-runbook.md`、品質の基準は `.claude/skills/app-quality-bar`
- 処理は画面から切り離してある：くじ `Scheduler`、結果 `Analyzer`（並べ替え検定・差の分布）、保存 `ExperimentStore`、型 `TemplateLibrary`、案 `ExperimentDesigner`（テストでは偽物）、画面の文 `Greeting`・`DetailText`・`DraftProblem`
